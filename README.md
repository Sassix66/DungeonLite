# DungeonLite

Eigenständiges minimalistisches Browser-RPG mit anklickbaren Dungeonfeldern.

## Version 0.3

- Kachelbasierte Dungeon-Ansicht
- Felder werden nacheinander freigeschaltet
- Gegnerfelder
- Schatzfelder
- Schreine
- Blockaden
- Bossfeld
- Ausgang zum nächsten Abschnitt
- Kämpfe
- Loot und Ausrüstung
- Inventar
- Speichern und Laden
- Responsive Design
